# Windows 使用指南

## 交互式终端面板（开发入口）

双击项目根目录的 `校圈监控.cmd` 可打开 Textual 终端界面。它每 1.5 秒读取本地运行状态和只读 SQLite，不会因为刷新而请求论坛或发送 Bark。主区域只显示帖子消息流；无新帖时保持不变。最近 100 条记录从 SQLite 恢复，正文预览会隐藏常见凭证、Cookie、手机号和邮箱格式。

底部输入框支持 `↑/↓` 选择命令补全、`Tab` 补全和 `Enter` 执行：

- `/start` 启动监控或连接已有后台进程。
- `/status` 查看完整状态、统计和诊断。
- `/posts` 打开历史帖子列表；`↑/↓` 滚动，`/home` 返回实时消息流。
- `/help` 查看命令；`/stop` 二次确认后请求后台受控停止。
- `/quit`、`Ctrl+C` 或关闭终端只退出界面，后台监控继续运行。

打开界面不会自动启动监控。`Bark 已接受` 表示 Bark 服务端接受请求，不代表手机已送达。

当前 TUI 作为开发入口新增，尚未替换原有生产 `.cmd` 入口。确认迁移前，继续通过现有入口管理生产实例。

## 准备环境

需要 Windows 10/11、Python 3.12 和 [uv](https://docs.astral.sh/uv/)。克隆项目后，在项目根目录安装锁定依赖：

```powershell
git clone https://github.com/Jiajun-H/zuel-dora-campus-watch.git
cd zuel-dora-campus-watch
uv sync --locked
```

想先体验离线流程，可运行：

```powershell
uv run --locked python -m campus_watch demo
```

该演示使用合成数据，不会连接真实来源或发送通知。

## 当前生产入口（保持原样）

在文件资源管理器中打开项目文件夹，依次使用根目录中的三个入口：

- `启动监控.cmd`：启动后台监测。首次配置 Bark 时会以隐藏输入方式询问推送密钥；密钥通过当前 Windows 用户的本机保护机制保存。
- `查看监控状态.cmd`：查看监测状态、运行轮次和请求计数。
- `停止监控.cmd`：请求后台任务停止，并显示停止状态。

请保留项目目录结构，不要把 `.cmd` 文件单独移出项目文件夹。运行数据库、状态和日志保存在 `data/` 目录中。 启动入口默认读取 `config/freshness.daily.json`；`config/freshness.fixed.example.json` 与 `config/freshness.process.example.json` 展示不含凭证的策略样例。

悬赏监控每 60 秒检查固定的最新窗口，启动脚本默认扫描 2 页，最多使用每轮 3 次列表请求。首次启动或停机超过 15 分钟后会静默同步当前窗口，不批量补发历史帖。有限页数可能漏掉两次检查间移出窗口的新帖；未入库的历史帖若后来进入窗口，也可能被当作首次观察通知。已成功通知的帖子 ID 会持续用于防重。

## 凭证与访问边界

推送密钥应只在本机输入，不要写入源码、提交到 Git 或放入日志和截图。连接真实来源、持续监测或启用手机通知前，请确认自己有权访问，并遵守来源平台规则。
